# 小家路线规划

更新：2026-10-26

## 长期目标

**结婚一周年（2027-09-28）时，小家能生成我们的第一本「年度回顾」**：这一年一起花了多少、花在哪；去过哪些地方、吃过哪些菜；完成了多少件家务和待办；记下了哪些纪念日和回忆，最后接上答谢宴那天亲友的祝福。

所以在那之前，日常的账、清单、吃喝、出行和回忆都要真的记在小家里。衡量进度的标准只有一个：**两个人是不是每周都在用**。每条记录的 `date` / `ts` 要保持准确，删除前想一想是否值得留作回忆。

## 现在：把常用功能打磨顺手（2026-10-26 定）

不急着加新模块，先让每天用的地方少点几下。每步一个 PR，真机试过再做下一步。

| 顺序 | 内容                    | 要点                                                                                                                                        |
| ---- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 代码清理                | 删旧文档、`ai-suggest` 空壳和「所在城市」，截图记账拆文件，文档改成现状                                                                     |
| 2    | 记账                    | 明细按天分组并显示当天合计；顶部加「本月收入」；点「按分类」筛选明细；「保存并再记一笔」，分类默认上次用的；截图记账第 2 期（见下）         |
| 3    | 清单                    | 已完成默认折叠；购物清单显示最近买过的，点一下重新加入；T3 重复任务（勾选完成时生成下一条）                                                 |
| 4    | 吃啥                    | 两排筛选合并成一排；添加改成按钮，类型跟着当前筛选；F3「就吃这个」记下吃过，抽签避开最近 3 天                                               |
| 5    | 「我们」（周末 + 纪念） | 「周末」并入「纪念」，tab 改名「我们」，底部变 4 个 tab：纪念日、想去的地方、回忆。想去的地方加「去过了」和链接（W2、W3），回忆时间线（D2） |

全局：添加入口统一成一种；出错时的按钮统一叫「重试」。

截图记账第 2 期：记住「商户 → 分类」，下次导入自动套用；在设置里填对方在微信 / 支付宝上的名字，识别两人之间的转账并默认不记。方案见 [截图自动记账方案](https://claude.ai/artifact/5ygFp8YVzPVQ2pEzkWDP1d)。

## 之后

| 方向                | 说明                                                                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 年度回顾（2027 夏） | `api` 增加 `review.year`：全年支出与分类、完成的清单、吃过的、去过的、纪念日与回忆；排版适合截图，答谢宴祝福作为最后一页 |
| AI 推荐             | 吃啥、周末出主意。要做时照截图记账的做法放进 `api`，用千问，加每日调用上限                                               |
| 回忆照片（D3）      | 有存储费用，也要更新隐私保护指引                                                                                         |
| 其他增量            | M6 定期支出、M7 预算、T5 家务轮换、F4 否决权、W4 投票、G4 搜索、G5 深色模式                                              |

暂缓：

- **M8 导出 CSV**：已有「复制全部数据」（JSON）备份。
- **T4 / D4 提醒**：个人主体只能用一次性订阅消息，每次要点「允许」才有一次发送额度，体验一般。备选是 `wx.addPhoneCalendar` 写进手机日历。

不做：G3 首页总览（两个人用意义不大）、M9 多币种、三人以上。
