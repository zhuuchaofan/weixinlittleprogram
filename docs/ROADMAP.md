# 小家路线规划

更新：2026-10-30

## 长期目标

**结婚一周年（2027-09-28）时，小家能生成我们的第一本「年度回顾」**：这一年一起花了多少、花在哪；去过哪些地方、吃过哪些菜；完成了多少件家务和待办；记下了哪些纪念日和回忆，最后接上答谢宴那天亲友的祝福。

所以在那之前，日常的账、清单、吃喝、出行和回忆都要真的记在小家里。衡量进度的标准只有一个：**两个人是不是每周都在用**。每条记录的 `date` / `ts` 要保持准确，删除前想一想是否值得留作回忆。
