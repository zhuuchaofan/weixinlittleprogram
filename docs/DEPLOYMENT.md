# 云端准备与验收

以下操作需要登录微信后台或开发者工具，由你本人执行。

## 1. 数据库

1. 在云开发控制台新建集合 `households`，权限设为「自定义安全规则」：`{ "read": false, "write": false }`。
2. 确认旧集合 `rsvps`、`guest_messages` 仍在，规则保持 `{ "read": false, "write": false }`。归档页通过云函数读取，不需要放宽。
3. 旧集合 `photo_content`、`event_program` 不再使用，可以删除（2026-10-26 确认不留）。

## 2. 云函数

1. 开发者工具中右键 `cloudfunctions/api` →「上传并部署：云端安装依赖」。
2. `api` 不需要配置任何环境变量。
3. 旧云函数 `weddingApi` 不再调用，可以删除。

## 3. 验收

用两个微信号（真机）：

1. A 打开小程序 → 跳到「两个人的小家」→ 创建小家 → 在「纪念」页看到 6 位邀请码。
2. B 打开 → 用邀请码加入 → 进入主页。
3. A 回到「纪念」页刷新：邀请码消失，成员显示两人。
4. A 在设置里改自己的称呼并保存；B 进入「纪念」页能看到新称呼。
5. 第三个微信号用同一个邀请码加入，应提示「邀请码无效或已被使用」。
6. A、B 都能打开「答谢宴 · 登记与祝福」，人数和条数与原后台一致；第三个微信号无法读取。

## 阶段 2

1. 新建集合 `expenses`、`todos`，权限同样设为 `{ "read": false, "write": false }`。
2. 建议在 `expenses` 上添加索引：`householdId` 升序 + `date` 升序；`todos` 上添加 `householdId` 升序。
3. 重新部署 `cloudfunctions/api`（「上传并部署：云端安装依赖」）。

验收（两个微信号真机）：

1. A、B 各记 5 笔本月账，包含「两人平摊」「全算对方」「自己的」三种分摊；把每笔记下来手算：
   - 共同支出 = 除「自己的」外的金额合计；
   - 平摊记 1/2、全算对方记全额，A 付为正、B 付为负，合计为 net；net > 0 时 B 付给 A，四舍五入到分。
     页面上的共同支出、各自付款和结算金额应与手算一致。
2. 点「记为已结算」→ 出现一条结算记录，提示变为「本月已结清」；删除该结算记录后恢复原来的结算建议。
3. 编辑一笔账（改金额和付款人）、删除一笔账（有二次确认），对方刷新后能看到变化。
4. 清单：在三类里各加一条，指派给不同的人，勾选、取消勾选、编辑、删除；对方刷新后一致。
5. 「纪念」→「复制全部数据」，粘贴出来的文本能被任意 JSON 工具解析，条数与页面一致，里面没有 openid。
6. 断网时记一笔：页面提示失败，表单内容保留。

## 截图记账（第 1 期）

### 开通通义千问

1. 登录千问 AI 平台（原阿里云百炼），开通模型服务；在「模型」里确认 `qwen3.8-omni-flash` 可用（新用户一般有免费额度，在模型详情页「免费额度」查看）。
2. 在「API-KEY」页面创建一个 API Key（`sk-` 开头）。建议在阿里云「费用」里设一个每月预算提醒，比如 20 元。
3. 用量参考：每天 3～4 张截图，每月约 100 张；按 qwen3.8-omni-flash 的价格（输入 0.8 元 / 百万 Token，输出 2.7 元 / 百万 Token），每月不到 1 元。以千问 AI 平台显示的价格为准。

### 部署

1. 重新部署 `cloudfunctions/api`（「上传并部署：云端安装依赖」）。无新集合，已有账目不受影响（没有 `flow` 的旧账目算支出）。
2. 在云开发控制台 → 云函数 → `api` → 函数配置：
   - **超时时间改为 60 秒**（识别一张截图要 5～15 秒，默认 3 秒会超时）；
   - 环境变量新增 `DASHSCOPE_API_KEY`，值为上面的 API Key。密钥只放这里，不要写进代码或提交到 git。
   - 可选：`BILL_MODEL` 换模型（默认 `qwen3.8-omni-flash`）；`BILL_BASE_URL` 换接口地址（默认 `https://cn-beijing.maas.qianwenaiapi.com/compatible-mode/v1`）。
3. 云存储不用新建目录：截图临时上传到 `bill-screenshots/`，识别完马上删除。
4. 在公众平台「设置 → 服务内容声明 → 用户隐私保护指引」补充：收集「选中的照片或视频信息」，用途「识别账单截图生成记账记录」；并说明截图会交给第三方（阿里云通义千问）识别、识别后删除。
5. 上传体验版。
