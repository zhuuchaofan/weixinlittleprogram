# CloudBase 部署与收束

## 服务边界

客户端只调用 `weddingApi`；云函数从 `cloud.getWXContext().OPENID` 识别用户。前端的管理员菜单缓存不授予权限，云函数每次照片、登记、祝福管理操作都会校验真实 OpenID。

| 集合             | 用途                     | 客户端规则                          |
| ---------------- | ------------------------ | ----------------------------------- |
| `rsvps`          | 到场登记                 | `{ "read": false, "write": false }` |
| `guest_messages` | 仅主人可见的祝福         | `{ "read": false, "write": false }` |
| `photo_content`  | 照片草稿与已发布安排     | `{ "read": false, "write": false }` |
| `event_program`  | 当天流程草稿与已发布安排 | `{ "read": false, "write": false }` |

在 CloudBase 控制台为每个集合实际设置规则；仓库中的规则文件只是模板。存储应允许访客读取已展示图，但禁止客户端直接写入。草稿照片不能通过访客接口列出。

## 部署 weddingApi

1. 部署 `cloudfunctions/weddingApi`，按控制台要求安装 `wx-server-sdk`。
2. 保留并配置 `ADMIN_OPENIDS`：管理员 OpenID 以英文逗号分隔；为空即拒绝全部管理员操作。
3. 设置环境变量：

```text
COLLECTION_CLOSES_AT=2026-09-28T16:00:00.000Z
```

该时间等于中国时区 2026 年 9 月 29 日 00:00。截止后 `save` 和 `guestbookSave` 返回 `COLLECTION_CLOSED`；本人读取、本人删除和管理员汇总保持可用。4. 用管理员和普通访客两个微信账号测试。不要把 OpenID 发到前端、截图或仓库。

## 云图与音乐

照片 File ID 在显示时由客户端换取短期 HTTPS 地址。展示缩略图使用 `imageMogr2/thumbnail/1080x1080/format/webp/quality/85`，失败依次回退 PNG 缩略图与原文件；大图预览不加工。新图片使用授权文件直传，必须先部署新云函数，详见 [图片链路部署](IMAGE-PIPELINE.md)。此方案不创建缩略图文件、不更改照片数据库结构。

背景音乐配置已关闭。日后启用时只接受自有或已获公开播放授权的音频 File ID；不使用音乐平台试听地址或来源不明文件。

## 2026 年 12 月 27 日归档（由主人执行）

本次不删除任何真实数据。到期后，确认不再需要查看或导出数据，再在 CloudBase 删除 `rsvps` 和 `guest_messages` 中的记录。随后发布纯照片纪念册版本，移除登记、私密祝福、主人统计、对应 mock、模型、校验和云函数路由；保留照片册、请柬、故事、猫咪、隐私页、音乐能力和受 OpenID 鉴权的照片管理。

归档版的页脚管理员入口应直达照片管理，继续保留 `photo_content`、`weddingApi` 照片操作与 `ADMIN_OPENIDS`。清理后再次用管理员和访客验证：访客无法进入照片管理，管理员可维护照片，页面不再出现登记、祝福或统计入口。

## 答谢宴当天流程

1. 在云开发数据库创建 `event_program` 集合，规则同样设为 `{ "read": false, "write": false }`。
2. 部署最新版 `weddingApi`。流程草稿与发布仍由服务端根据 `ADMIN_OPENIDS` 校验。
3. 管理员进入“主人工作台 → 当天流程”，先保存草稿；确认无误后点击“更新展示”。只有 2026 年 9 月 28 日当天的首页会展示该流程。
4. 现场临时调整后重复“保存草稿 → 更新展示”。若需要回到代码预设，点击“恢复内置默认流程”，再发布才会影响亲友页面。
