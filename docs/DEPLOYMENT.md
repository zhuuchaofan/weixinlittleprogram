# CloudBase 部署与收束

照片库 V2 的备份、兼容部署与双账号验收顺序见 [统一照片库 V2](MEDIA-LIBRARY-V2.md)。

## 服务边界

客户端只调用 `weddingApi`；云函数用 `@cloudbase/js-sdk` 从当次调用的 `context` 解析 `WX_OPENID`，不信任请求体中的身份字段或可能因实例复用而残留的环境变量。前端的管理员菜单缓存不授予权限，云函数每次照片、登记、祝福管理操作都会校验真实 OpenID。

| 集合             | 用途                     | 客户端规则                          |
| ---------------- | ------------------------ | ----------------------------------- |
| `rsvps`          | 到场登记                 | `{ "read": false, "write": false }` |
| `guest_messages` | 仅主人可见的祝福         | `{ "read": false, "write": false }` |
| `photo_content`  | 照片草稿与已发布安排     | `{ "read": false, "write": false }` |
| `event_program`  | 当天流程草稿与已发布安排 | `{ "read": false, "write": false }` |

在 CloudBase 控制台为每个集合实际设置规则；仓库中的规则文件只是模板。存储应允许访客读取已展示图，但禁止客户端直接写入。草稿照片不能通过访客接口列出。

## 部署 weddingApi

1. 先在云开发控制台备份 `photo_content` 的 `draft` 与 `published` 原始文档，并保存当前 `weddingApi` 云函数版本以备回退。在微信开发者工具中右键 `cloudfunctions/weddingApi` →「上传并部署：云端安装依赖」，确认云端安装的是锁文件中的 `@cloudbase/js-sdk@3.10.1`。本地生产依赖审计为 0 项告警；云端依赖安装和 API 仍需在实际环境验证。
2. 保留并配置 `ADMIN_OPENIDS`：管理员 OpenID 以英文逗号分隔；为空即拒绝全部管理员操作。
3. 设置环境变量：

```text
COLLECTION_CLOSES_AT=2026-09-28T16:00:00.000Z
```

该时间等于中国时区 2026 年 9 月 29 日 00:00。截止后 `save` 和 `guestbookSave` 返回 `COLLECTION_CLOSED`；本人读取、本人删除和管理员汇总保持可用。

4. 保持 `photo_content`、`rsvps`、`guest_messages` 和 `event_program` 的客户端读写规则，以及云存储现有权限。新版 JS SDK 的数据库与存储调用需在云开发平台检查 HTTP API 策略是否允许云函数访问；不要放宽访客权限。
5. 用管理员与普通访客两个微信账号在真机检查：`getAccess` 结果、旧照片和私密过滤、草稿与发布、图片及视频 POST 上传、播放、文件引用删除保护、登记和祝福读取。开启合法域名校验；不要把 OpenID、上传签名或完整 File ID 发到截图和日志。
6. 若出现数据库访问、上传签名或身份解析失败，停止提审，恢复备份的云函数版本。数据文档未由依赖升级迁移，不需为回退改写数据。

## 云图与音乐

照片 File ID 在显示时由客户端换取短期 HTTPS 地址。展示缩略图使用 `imageMogr2/thumbnail/1080x1080/format/webp/quality/85`，失败依次回退 PNG 缩略图与原文件；大图预览不加工。新图片使用授权文件直传，必须先部署新云函数，详见 [图片链路部署](IMAGE-PIPELINE.md)。此方案不创建缩略图文件、不更改照片数据库结构。

背景音乐配置已关闭。日后启用时只接受自有或已获公开播放授权的音频 File ID；不使用音乐平台试听地址或来源不明文件。

## 答谢宴当天流程

2. 部署最新版 `weddingApi`。流程草稿与发布仍由服务端根据 `ADMIN_OPENIDS` 校验。
3. 管理员进入“主人工作台 → 当天流程”，先保存草稿；确认无误后点击“更新展示”。只有 2026 年 9 月 28 日当天的首页会展示该流程。
4. 现场临时调整后重复“保存草稿 → 更新展示”。若需要回到代码预设，点击“恢复内置默认流程”，再发布才会影响亲友页面。
