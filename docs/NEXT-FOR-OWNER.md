```ts
  cloudEnvId: string;
  mockAdminEnabled: boolean;

  cloudEnvId: '在这里填你的环境ID',
  mockAdminEnabled: false,

```

## 上传照片到云存储

1. 在云开发面板进入「云存储」，确认左上角环境 ID 与 `local.ts` 相同。
2. 用「新建文件夹」建立 `wedding/cover`、`wedding/thumb`、`wedding/original`；上传的展示图、缩略图和较清晰大图区分保存。
3. 使用「上传文件」上传照片。建议先保留原始文件在自己的电脑，只把衍生图传到云端：缩略图长边约 600–900 px，大图约 1600–2200 px。
4. 每个文件上传成功后，复制它的 File ID（以 `cloud://` 开头），填入 `miniprogram/config/content.ts` 对应照片的 `thumbnail`、`original`；同时把 `placeholder` 改为 `false`。
5. 重新编译，用真机打开相册并点大图。若云图私有读，项目会在每次进入页面时换取短期访问链接；不用也不应把该链接写入配置。

照片展示给所有受邀访客时，需要在云存储规则中允许读取展示图片、禁止普通客户端写入。照片的展示方式和相册是否可转发由你最后确认；不要上传未获当事人同意公开展示的原图。
