# 提审前核验清单

这份清单用于“隐私整改版本”上线前留证。代码通过不代表公众平台、备案、认证或类目已经通过；以下账号侧动作只能由主体账号持有人完成。

## 1. 先完成代码与部署

1. 在 `miniprogram/config/content.ts` 的 `appConfig.privacyContact.account` 填入真实可用的微信号；不填写密码、OpenID、身份证或支付信息。
2. 在微信开发者工具部署 `cloudfunctions/weddingApi`，选择云端安装依赖，保留 `ADMIN_OPENIDS` 环境变量。
3. 云开发数据库确认 `rsvps` 和 `photo_content` 的自定义安全规则都是：

```json
{ "read": false, "write": false }
```

4. 云存储确认访客可以读取已展示图片、客户端不能写入；不要为了手机上传开放客户端写权限。
5. 重新编译并上传体验版。体验版、开发版和正式版使用的云环境必须一致。

## 2. 在公众平台填写隐私保护指引

按平台当天显示的字段逐项选择和填写，内容必须与小程序一致：

- 到场登记：称呼、是否到场、人数、备注和最近修改时间，仅用于宴会安排。
- 微信账号标识：OpenID 仅由云函数用于一人一条登记和管理员鉴权，不向其他亲友展示。
- 管理员选图：只有管理员主动点击后从手机相册选择一张照片；照片上传到 CloudBase，发布后供受邀亲友浏览。
- 不声明未实际使用的手机号、身份证、支付、精确位置、通讯录或用户头像等项目；地图按钮只打开场地，不读取访客位置。
- 联系渠道填写与小程序相同的真实微信号；说明访客可在隐私页删除自己的登记。

同时配置体验版隐私指引。管理员点击“从手机添加照片”时，应看到微信原生授权；拒绝后不应进入相册。

## 3. 双账号与真机验收

| 场景                                      | 预期结果                                                       | 留证                     |
| ----------------------------------------- | -------------------------------------------------------------- | ------------------------ |
| 访客填写、修改、删除登记                  | 仅影响自己的唯一记录                                           | 两台微信或两账号截图     |
| 访客进入主人工作台、直接调照片管理 action | 页面不可见或服务端拒绝                                         | 云函数响应/日志          |
| 管理员选图                                | 先出现原生隐私授权；拒绝不选图，同意后可上传                   | iPhone、安卓各一次       |
| 草稿与发布                                | 保存草稿不影响访客；更新展示后访客可见                         | 前后对比截图             |
| 文件清理                                  | 已引用文件拒绝删除；未引用 `wedding/managed/` 文件允许永久删除 | 管理页引用数与云存储结果 |
| 图片与断网                                | 预览返回不出现加载遮罩；断网后保留已显示照片并可恢复           | 两种机型截图             |

不要在截图、日志或提审材料中公开 OpenID、完整 File ID、宾客备注或管理员名单。
