## 2. 在公众平台填写隐私保护指引

按平台当天显示的字段逐项选择和填写，内容必须与小程序一致。平台字段名称可能调整，按信息类型与实际用途对应，不要勾选未使用的能力。

- 到场登记：称呼、是否到场、人数、备注和最近修改时间，仅用于宴会安排。
- 私密祝福：可选署名、祝福正文和最近修改时间，仅供主人查看，不公开给亲友。
- 微信账号标识：OpenID 仅由云函数用于让每人维护自己的一条登记或祝福、以及判断管理员身份；不向其他亲友或接口响应公开。
- 选中的照片或视频信息：只有管理员主动点击“从手机添加照片”后才会从相册选择；照片上传到 CloudBase，发布后供受邀亲友浏览。
- 剪贴板：点击复制地址，或管理员复制照片 File ID、诊断信息时，将当次内容写入设备剪贴板以便粘贴；不读取剪贴板中的其他内容。
- 不声明未实际使用的手机号、身份证、支付、精确位置、通讯录、用户头像、麦克风或摄像头等项目；地图按钮只打开场地，不读取访客位置。
- 联系渠道填写与小程序相同的真实微信号；说明访客可删除自己的登记或祝福，主人在宴会结束后 90 天内清理相关数据。

同时配置体验版隐私指引。管理员点击“从手机添加照片”时，应看到微信原生授权；拒绝后不应进入相册。
