# 喵喵记一笔 设计规范

更新：2026-10-27。这份规范是把现在的界面归纳出来的，不是新风格。新页面、改页面都照这里来；想破例，先在这里改规则。

一句话风格：**浅底白卡片、一张主题色渐变大卡片当主角、线条小猫图标、圆角大、字少**。

## 1. 颜色：只用主题变量

所有颜色写在 `miniprogram/app.wxss` 顶部，5 套主题在 `config/themes.ts` 里覆盖同名变量（默认香芋紫）。**页面 wxss 里不写色值**，`npm test` 会检查。

| 变量                             | 用在哪                                    |
| -------------------------------- | ----------------------------------------- |
| `--paper`                        | 页面底色                                  |
| `--surface`                      | 卡片、列表、输入框                        |
| `--sunken`                       | 分段切换的底、进度条底、按下去的颜色      |
| `--ink` / `--muted`              | 正文 / 次要文字                           |
| `--line`                         | 分隔线、输入框边框                        |
| `--accent` / `--accent-soft`     | 主色文字和图标 / 浅主色底（标签、小按钮） |
| `--accent-grad`                  | 主按钮、渐变大卡片、勾选后的圈            |
| `--ring`                         | 没勾的圈、虚线                            |
| `--glow` / `--tint` / `--shadow` | 主色阴影 / 选中项阴影 / 卡片阴影          |
| `--ok`                           | 收入、完成、没超预算                      |
| `--danger` / `--danger-soft`     | 出错、超支、删除（不跟主题变）            |
| `--warn`                         | 提醒（不跟主题变）                        |

例外只有一个：渐变卡片上的字和白按钮用 `#fff`。分类颜色来自 `config/options.ts`，写在 `style` 里。

## 2. 间距阶梯

只用这几档（rpx）：**4 · 8 · 12 · 16 · 20 · 24 · 32 · 48**。常用的已经做成变量：

| 场景                               | 值  | 变量       |
| ---------------------------------- | --- | ---------- |
| 图标和文字、上下两行字             | 8   | `--gap-xs` |
| 一行里的元素之间、输入框和按钮之间 | 16  | `--gap-sm` |
| **卡片和卡片之间**、卡片和上方内容 | 24  | `--gap`    |
| 卡片内边距、块标题上方             | 32  | `--gap-lg` |
| 设置页这种大块之间                 | 48  | `--gap-xl` |

页面左右留白 32，底部留 `.page-end`。

## 3. 字号

| 用途                          | 字号             |
| ----------------------------- | ---------------- |
| 渐变大卡片里的数字            | 72–80，加粗 800  |
| 普通卡片里的金额              | 48–64            |
| 页面大标题 `.title`           | 56               |
| 块标题 `.section-title`、月份 | 34，加粗         |
| 正文、按钮                    | 30（主按钮 600） |
| 列表里的分类名、说明          | 28               |
| 表单标签、提示条              | 26               |
| 小字 `.small`、副标题         | 24               |

## 4. 圆角

卡片、列表、渐变卡片 `--radius`（32）；按钮、输入框、提示条 `--radius-sm`（20）；标签、胶囊、浮动按钮全圆；头像、勾选圈、色点用 50%。

## 5. 组件

- **卡片** `.card`：白底、32 内边距、卡片阴影。连续两张自动隔 24；页面自己写的卡片类也要隔 24（`.x + .x { margin-top: var(--gap); }`）。
- **列表** `.list` + `.list-row`：一行至少 112 高，中间细线不顶到边。
- **渐变大卡片** `.grad-card`：每页最多一张，放最重要的一个数（本月支出、下一个纪念日、今天吃啥）。上面的按钮用白底主色字。
- **按钮**：
  - 主按钮 `.primary`：渐变、白字、92 高、整行宽。一页最多一个主按钮。
  - 次按钮 `.secondary`：白底。
  - 行内按钮 `.btn-inline`：输入框旁边的「添加」。
  - 小按钮 `.btn-small`：卡片里的「存了一笔」「写小结」，64 高、浅主色底。
  - 文字按钮 `.text-button`、删除 `.danger-button`。
- **分段切换** `.segmented`、**胶囊** `.chips`、**勾选圈** `.tick`、**月份切换** `.month-bar`、**分类色点** `.cat-dot`、**折叠标题** `.fold-head`：都在 `app.wxss`，直接用。
- **空状态** `.empty`：虚线框 + 一句话，告诉人下一步点哪儿。加载中用 `.status`，出错用 `.notice.error` + 「重试」按钮。
- **图标**：线条小猫和线条图标在 `images/cat-icons`、`images/ui`，按主题换色的在 `images/themes`（`scripts/theme-icons.py` 生成）。列表前面的图标放在 `.tile` 色块里。
- **等待动画**：截图识别时的小猫喝茶（`pages/bill-import`），以后要等超过 3 秒的地方复用它。

## 6. 按钮文字上下居中

全局 `button` 已经是 flex 居中，**正常写 `<button class="primary">` 就居中**。容易出问题的两种：

1. **不要用 `size="mini"`**。基础库给它的 `display` 和行高会盖掉全局的 flex，字会偏上（`npm test` 会检查）。小按钮用 `class="btn-small"`。
2. **页面里改按钮的外边距或宽度**，选择器要写成 `.x, button.x:not([size='mini'])`，不然盖不过全局的 `margin: 0`、`width: 100%`。要自己定高度时写 `height` + `line-height: 1`，不要只靠 padding 撑。

按钮里的「+」用 `<text class="plus">+</text>`。

## 7. 写法约定

- 公共的东西放 `app.wxss`，页面 wxss 只写本页特有的布局。两个页面写了一样的样式，就挪到 `app.wxss`。
- 按下去的反馈用 `hover-class`，颜色 `--sunken` 或 `opacity: 0.7`。
- 点按区域至少 88 高（图标按钮、月份箭头、文字按钮）。
- 文案大白话，出错按钮统一叫「重试」。
