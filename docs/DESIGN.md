# 喵喵记一笔 设计规范

更新：2026-11-10（加了「保存、删除、返回」「AI 文案」两节，按钮和空状态的规则写细了）。这份规范是把现在的界面归纳出来的，不是新风格。新页面、改页面都照这里来；想破例，先在这里改规则。

一句话风格：**浅底白卡片、一张主题色渐变大卡片当主角、线条小猫图标、圆角大、字少**。

## 1. 颜色：只用主题变量

所有颜色写在 `miniprogram/app.wxss` 顶部，5 套主题在 `config/themes.ts` 里覆盖同名变量（默认香芋紫）。**页面 wxss 里不写色值**，`npm test` 会检查。

| 变量                             | 用在哪                                    |
| -------------------------------- | ----------------------------------------- |
| `--paper`                        | 页面底色                                  |
| `--surface`                      | 卡片、列表、输入框                        |
| `--sunken`                       | 分段切换的底、进度条底、按下去的颜色      |
| `--ink` / `--muted`              | 正文 / 次要文字                           |
| `--line`                         | 分隔线、输入框边框                        |
| `--accent` / `--accent-soft`     | 主色文字和图标 / 浅主色底（标签、小按钮） |
| `--accent-grad`                  | 主按钮、渐变大卡片、勾选后的圈            |
| `--ring`                         | 没勾的圈、虚线                            |
| `--glow` / `--tint` / `--shadow` | 主色阴影 / 选中项阴影 / 卡片阴影          |
| `--ok`                           | 收入、完成、没超预算                      |
| `--danger` / `--danger-soft`     | 出错、超支、删除（不跟主题变）            |
| `--warn`                         | 提醒（不跟主题变）                        |

例外只有一个：渐变卡片上的字和白按钮用 `#fff`。分类颜色来自 `config/options.ts`，写在 `style` 里。

## 2. 间距阶梯

只用这几档（rpx）：**4 · 8 · 12 · 16 · 20 · 24 · 32 · 48**。常用的已经做成变量：

| 场景                               | 值  | 变量         |
| ---------------------------------- | --- | ------------ |
| 图标和文字、上下两行字             | 8   | `--gap-xs`   |
| 一行里的元素之间、输入框和按钮之间 | 16  | `--gap-sm`   |
| **卡片和卡片之间**（小猫探头）     | 56  | `--gap-card` |
| 卡片和上方内容、提示条             | 24  | `--gap`      |
| 卡片内边距、块标题上方             | 32  | `--gap-lg`   |
| 设置页这种大块之间                 | 48  | `--gap-xl`   |

页面左右留白 32，底部留 `.page-end`。

## 3. 字号

| 用途                          | 字号             |
| ----------------------------- | ---------------- |
| 渐变大卡片里的数字            | 72–80，加粗 800  |
| 普通卡片里的金额              | 48–64            |
| 页面大标题 `.title`           | 56               |
| 块标题 `.section-title`、月份 | 34，加粗         |
| 正文、按钮                    | 30（主按钮 600） |
| 列表里的分类名、说明          | 28               |
| 表单标签、提示条              | 26               |
| 小字 `.small`、副标题         | 24               |

## 4. 圆角

卡片、列表、渐变卡片 `--radius`（32）；按钮、输入框、提示条 `--radius-sm`（20）；标签、胶囊、浮动按钮全圆；头像、勾选圈、色点用 50%。

## 5. 组件

- **卡片** `.card`：白底、32 内边距、卡片阴影。连续两张自动隔 56（给探头小猫留高度）；页面自己写的卡片类也要隔 56（`.x + .x { margin-top: var(--gap-card); }`）。
- **列表** `.list` + `.list-row`：一行至少 112 高，中间细线不顶到边。
- **渐变大卡片** `.grad-card`：每页最多一张，放最重要的一个数（本月支出、下一个纪念日、今天吃啥）。上面的按钮用白底主色字。
- **按钮**：
  - 主按钮 `.primary`：渐变、白字、92 高、整行宽。一页最多一个主按钮。
  - 次按钮 `.secondary`：白底。
  - 行内按钮 `.btn-inline`：输入框旁边的「添加」。
  - 小按钮 `.btn-small`：卡片里的「存了一笔」「写小结」，64 高、浅主色底。
  - 文字按钮 `.text-button`、删除 `.danger-button`。
  - **按钮上的字**：动词开头、说清做什么，2–6 个字。固定叫法：存东西叫「保存」，输入框旁边的叫「添加」，列表页新建是「+ 新目标」这种带加号的，删除是「删除这条 / 这笔账 / 这个目标」，出错后是「再试一次」，去会员页是「看看会员」，提示条收起是「知道了」。不用「确定」「提交」「OK」。
  - **按钮间距**：全局样式把按钮外边距清零，页面里写 `.x { margin-top }` 对按钮不生效。直接放在 `.page` 里、紧跟在别的块后面的按钮，`app.wxss` 的 `.page > view + button` 自动隔 24；要别的值，用 `button.x:not([size='mini']) { margin-top: … }`（选择器要比全局的高）。
- **分段切换** `.segmented`、**胶囊** `.chips`、**勾选圈** `.tick`、**月份切换** `.month-bar`、**分类色点** `.cat-dot`、**折叠标题** `.fold-head`：都在 `app.wxss`，直接用。
- **出错提示** `.notice.error`：浅灰底、正常字色、前面自动带一只小猫，不用红色；后面的按钮写「再试一次」。文案像朋友说话，说清发生了什么、下一步怎么做，不用「错误」「失败」「无效」「异常」「不支持」这类词，例如「网络好像开小差了，刚才没完成，稍后再试一次吧」。界面上只显示 `ApiError` 的提示，程序里的意外错误由 `errorMessage()` 换成温和的话。
- **空状态** `.empty`：虚线框 + 睡觉的小猫（`<image class="empty-cat" src="/images/themes/{{themeId}}/cat-sleep.svg" />`）+ 一句话，告诉人下一步点哪儿。加载中用 `.status`，文字前放走路的猫爪印（`.status-paws`，照现有页面抄），出错用 `.notice.error` + 「再试一次」按钮。空状态的那句话分两半：先说现在没有什么，再说去哪儿加（「这个月还没有记账。点下面的『记一笔』开始。」），不要只写「暂无数据」。加载中的字统一是「正在读取…」。
- **猫咪元素**：名字叫喵喵记一笔，新页面别忘了小猫。小猫一律是**实心、淡阴影、深色眼睛**，和白卡片一个质感，不画主色线条猫。勾选圈勾上后是白色猫爪（`.tick-paw`，`images/ui/paw.png`），不是「✓」（`npm test` 会检查）；渐变大卡片右上角是淡白猫头剪影（`.grad-card::after`，不用自己加）；白卡片 `.card`、列表 `.list`、主页入口右上角自动趴着一只小猫，6 种姿势（探头、趴着睡、坐着、伸懒腰、歪头眯眼、趴在边上）和毛色按顺序轮流（`::before`，图由 `scripts/card-cats.py` 写进 `app.wxss`，不跟主题变色），所以 `.card`、`.list` 别再写 `overflow: hidden` 或自己的 `::before`，卡片之间用 `--gap-card`（56）给小猫留高度；`.section-head`、`.fold-head` 右边已经留了 120 给下面卡片的小猫，标题行右边的小字不会被挡；主页宫格图标都带猫耳朵。文案偶尔带一个「喵」就够，别每句都加。
- **图标**：线条小猫和线条图标在 `images/cat-icons`、`images/ui`，按主题换色的在 `images/themes`（源文件在 `assets/theme-src`，主色写 `#f2614f`，`scripts/theme-icons.py` 生成；`npm test` 会检查每套主题都有）。列表前面的图标放在 `.tile` 色块里。
- **等待动画**：截图识别时的小猫喝茶（`pages/bill-import`），以后要等超过 3 秒的地方复用它。

## 6. 动效

都写在 `app.wxss` 的「动效」一段，新页面用公共类就自动有，不用自己写：

- **进场**：`.card`、`.list`、`.grad-card`、`.grid-cell`、`.empty`、`.section-head` 等从下面浮上来（0.48 秒），按在页面里的顺序错开 0.04 秒。
- **数据**：进度条（`.saving-bar`、`.goal-bar`、`.budget-bar`、`.compare-bar`、`.hero-share`）从左长出，柱子 `.trend-bar` 从下长出。
- **反馈**：按下缩放见上面「写法约定」；`.tick-on` 勾上时盖章，`.chip-on`、`.segment-on` 选中时回弹一下。
- **一直在动的**只有空状态的睡猫呼吸、欢迎页小猫浮动和心跳，别的地方不加循环动画（费电）。

规则：只动 `transform` 和 `opacity`（低端机也顺），时长 0.2–0.9 秒；`animation` 的填充用 `backwards`，不要 `both` / `forwards`，否则会盖住按下去的缩放；新加的动画写进末尾 `prefers-reduced-motion` 那段，系统开了减弱动态效果就不放。

## 7. 数字

金额、天数用等宽数字（`font-variant-numeric: tabular-nums`，常用的类已经加了）。页面上最大的那个金额，「¥」拆出来小一号：

```html
<wxs module="money" src="../../wxs/money.wxs" />
<view class="hero-total"
  ><text wx:if="{{money.sign(totalText)}}" class="cur">¥</text
  >{{money.digits(totalText)}}</view
>
```

## 8. 按钮文字上下居中

全局 `button` 已经是 flex 居中，**正常写 `<button class="primary">` 就居中**。容易出问题的两种：

1. **不要用 `size="mini"`**。基础库给它的 `display` 和行高会盖掉全局的 flex，字会偏上（`npm test` 会检查）。小按钮用 `class="btn-small"`。
2. **页面里改按钮的外边距或宽度**，选择器要写成 `.x, button.x:not([size='mini'])`，不然盖不过全局的 `margin: 0`、`width: 100%`。要自己定高度时写 `height` + `line-height: 1`，不要只靠 padding 撑。

按钮里的「+」用 `<text class="plus">+</text>`。

## 9. 写法约定

- 公共的东西放 `app.wxss`，页面 wxss 只写本页特有的布局。两个页面写了一样的样式，就挪到 `app.wxss`。
- 按下去的反馈用 `hover-class`，颜色 `--sunken` 或 `opacity: 0.7`。卡片、入口按下去会缩到 0.98、按钮 0.96（`app.wxss` 已经写好，`.card-active`、`.grid-cell-active`、按钮默认的 `button-hover`）。
- 点按区域至少 88 高（图标按钮、月份箭头、文字按钮）。
- 文案大白话，出错按钮统一叫「再试一次」（`npm test` 会检查页面里没有「重试」）。

## 10. 保存、删除、返回

所有编辑页（记一笔、清单、吃啥、想去、纪念日、攒钱目标、分类预算）一个样，照 `utils/feedback.ts` 和 `utils/confirm.ts` 写：

- **保存**：页面最下面一个主按钮「保存」，按下去转圈、不能再点。成功后轻提示「已保存」，约半秒后自动回上一页（`await doneBack()`）。没填对时不弹窗，在按钮上面用 `.notice.error` 说哪儿没填好，填的内容留着。
- **留在本页的保存**（设置里的名字）：只轻提示「已保存」（`doneStay()`），不用提示条。
- **列表页直接加**（输入框 + 「添加」）：加完清空输入框、新的一条出现在列表里，就是反馈，不再弹提示。
- **删除**：红字文字按钮放在保存下面。先弹确认（`confirmAction`）：标题问「删除这条？」，内容说后果，按钮是动作本身（「删除」「清除」「退出」「注销」，红字）和「再想想」；微信限制按钮最多 4 个字。删完轻提示「已删除」，自动回上一页（`await doneBack('已删除')`）。
- **返回**：左上角返回不拦、不问「要不要保存」，没保存的修改直接丢掉；所以表单要短，一屏填完。
- **轻提示**（toast）只用来说「做成了」，7 个字以内；出错的话太长，放 `.notice.error`。只有不在表单里的小操作（主页点回应）出错才用轻提示。
- **弹窗**（modal）只用在三处：删不回来的确认、第一次用某个功能前的说明（截图记账、喵喵帮忙）、需要人停下来看的结果（超预算、攒够了、已注销）。按钮写「知道了」，不写「确定」。

## 11. AI 文案

小程序里所有用到 AI 的地方一个说法，新加 AI 功能照这几条写：

- **叫法**：对人说话时主语是「喵喵」（喵喵小结、年度寄语、让喵喵拆成多条、喵喵帮你拆）；讲规则和合规说明时才写「AI」。功能清单（会员权益、设置、购买须知）统一用契约里的名字，从 `config/options.ts` 的 `AI_NAMES` 取，不要手抄。
- **标识**：AI 写出来的内容所在的卡片，标题右边一律放 `<text class="tag">AI 生成</text>`，不写「AI 整理」「智能」之类别的字（`npm test` 会检查）。
- **用之前的说明**（还没内容时卡片里的灰字）：一句话说喵喵会做什么，接着「由阿里云通义千问生成，只发…，不发…」。一句话加清单、一句话记账第一次用时弹一次「喵喵帮忙说明」（`services/assist.ts`），截图记账弹「截图记账说明」。
- **内容下面的小字**：「以上内容由 AI 根据<用了什么>生成，仅供参考。」后面按情况接「不会保存。」或「确认后才保存。」。
- **按钮**：第一次是「写小结」「写寄语」「帮我拆成几笔」「让喵喵拆成多条」这种动词 + 东西；已经有内容后统一叫「重新写」。不用「生成」「重新生成」当按钮字。
- **等的时候**：「喵喵正在看账本…（十几秒）」这种，说喵喵在干什么、大概多久。
- **次数用完**：云端的提示照「今天已经写了 2 次，明天再来吧。开通会员每天可以写 20 次。」的样子，下面放文字按钮「看看会员」。
- **不夸大**：不说「智能」「精准」「懂你」，不保证对；识别、挑选的结果都要人确认后才保存。
